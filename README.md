# 🚀 Video Streaming Software - Deployment Guide

এই সফটওয়্যারটি যেকোনো প্ল্যাটফর্মে (যেমন Render, Railway, Oracle Cloud, বা VPS) হোস্ট করার জন্য নিচের নির্দেশনাগুলো অনুসরণ করুন।

## ১. প্রয়োজনীয়তা (Requirements)
- **Node.js 20+**
- **FFmpeg:** স্ট্রিমিং করার জন্য এটি অবশ্যই সার্ভারে ইনস্টল থাকতে হবে।
- **SQLite3:** ডাটাবেস হিসেবে এটি ব্যবহৃত হচ্ছে।

## ২. হোস্টিং প্ল্যাটফর্ম অনুযায়ী সেটআপ

### Render.com (Free)
1. Render-এ একটি নতুন **Web Service** তৈরি করুন।
2. আপনার GitHub রিপোজিটরি কানেক্ট করুন।
3. **Build Command:** `npm install && npm run build`
4. **Start Command:** `npm run start`
5. **Disk (Optional):** Render-এর ফ্রি টায়ারে ডিস্ক থাকে না, তাই সার্ভার রিস্টার্ট হলে ভিডিও মুছে যাবে। ভিডিও স্থায়ীভাবে রাখতে একটি "Disk" মাউন্ট করুন (Paid)।

### Railway.app (Recommended)
1. Railway-তে নতুন প্রজেক্ট তৈরি করুন।
2. GitHub রিপোজিটরি কানেক্ট করুন।
3. Railway স্বয়ংক্রিয়ভাবে `Dockerfile` বা `Procfile` দেখে এটি সেটআপ করে নেবে।
4. **Volume:** একটি ভলিউম (Volume) তৈরি করে `/app/uploads` এবং `/app/streaming.db` পাথটি মাউন্ট করুন যাতে আপনার ডাটা মুছে না যায়।

### Docker (Universal)
আপনি যদি Docker ব্যবহার করতে চান, তবে সরাসরি এই কমান্ডটি ব্যবহার করতে পারেন:
```bash
docker build -t streaming-app .
docker run -p 3000:3000 streaming-app
```

## ৩. এনভায়রনমেন্ট ভেরিয়েবল (Environment Variables)
- `NODE_ENV`: `production`
- `DATA_DIR`: যেখানে ডাটাবেস এবং ভিডিও জমা থাকবে (যেমন `/data`)।

## ৪. সাধারণ সমস্যা ও সমাধান
- **FFmpeg Not Found:** যদি সার্ভারে FFmpeg না থাকে, তবে স্ট্রিমিং শুরু হবে না। নিশ্চিত করুন যে আপনার হোস্টিং প্ল্যাটফর্মে FFmpeg সাপোর্ট আছে।
- **Database Locked:** যদি একাধিক প্রসেস একই ডাটাবেস ব্যবহার করার চেষ্টা করে, তবে এই এরর হতে পারে।

## ৫. ভিডিও স্থায়ীভাবে রাখা (24/7 Persistence)
আপনার আপলোড করা ভিডিওগুলো যাতে কখনোই মুছে না যায়, সেজন্য নিচের টিপসগুলো অনুসরণ করুন:
- **Volume Mounting:** আপনার হোস্টিং প্ল্যাটফর্মে একটি ভলিউম (Volume) তৈরি করুন এবং সেটিকে `/data` পাথে মাউন্ট করুন।
- **Storage Limit:** ডিফল্টভাবে ৫০০জিবি লিমিট দেওয়া আছে। আপনি চাইলে `STORAGE_LIMIT_GB` এনভায়রনমেন্ট ভেরিয়েবল ব্যবহার করে এটি বাড়াতে পারেন।
- **Backup:** নিয়মিত `streaming.db` এবং `uploads` ফোল্ডারটির ব্যাকআপ রাখুন।
